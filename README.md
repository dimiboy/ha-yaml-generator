An interactive visual Home Assistant template tester and generator. Test, debug, and format sensor math, timestamp calculations, and Telegram alert templates in seconds without crashing Home Assistant on boot.

---

## ⚡ Features

- **Safe Boot Defaults**: Auto-handles `| float(0)` and `| int(0)` to eliminate Home Assistant boot-time template crashes.
- **DateTime & Relative Math**: Instant relative uptime, timestamp parsing, and sensor delta formatting.
- **Conflict-Free Telegram Payloads**: Formats valid Telegram HTML alert templates with zero parse errors.
- **State & Entity Summary**: Generates compact count filters for lights, batteries, offline devices, and switches.
- **100% Client-Side**: Fast, responsive, runs completely in-browser with zero tracking or telemetry.
